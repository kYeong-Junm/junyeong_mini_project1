## 📌 프로젝트 개요

Online Retail II 데이터셋은 인보이스 번호가 'C'로 시작하면 취소 거래라는 것이 잘 알려져 있다. 그런데 이 지식은 대부분의 분석에서 딱 한 줄로만 소비된다.

> "취소 거래는 분석에 방해되니 제거하고, 정상 거래만으로 매출을 분석하겠다."

즉 '취소 여부'라는 정보는 거의 항상 전처리 단계에서 걸러내야 할 노이즈로 취급되고, 그 이후 분석(매출 추이, RFM 세그멘테이션, 판매량 예측 등)의 대상에서는 제외된다.

본 프로젝트는 취소 거래를 제거하지 않고, 오히려 **취소 거래 자체가 무엇을 말해주는가**를 핵심 연구 대상으로 삼는다. 취소가 특정 국가, 특정 시간대, 특정 상품, 특정 주문 규모에 몰려서 발생한다면, 이는 가격 정책 오류, 상품 품질 문제, 혹은 특정 고객군의 이탈 전조를 나타내는 신호일 수 있다.

---

## 🎯 연구 배경 및 필요성

- 유통업체는 취소·반품 발생 시 재고 관리, 배송비, 고객 응대 등 추가 비용이 발생하지만, 취소가 "왜, 어디서" 집중적으로 발생하는지 파악하지 못하면 문제의 근본 원인에 대응할 수 없다.
- 취소는 가격 실수, 상품 품질 문제, 대량주문 관련 리스크, 특정 고객군의 구매 후회 등 여러 원인이 섞여 나타날 수 있어, 직관만으로는 어떤 요인이 실제로 취소에 기여하는지 구분하기 어렵다.
- 기존 이커머스 분석은 취소를 노이즈로 걸러낸 정상 거래 중심의 매출·세그멘테이션 분석에 집중되어 있어, 취소 자체를 설명하는 분석 관점이 상대적으로 드물다.

## 🔍 연구 목적

1. 국가별·요일/시간대별로 취소율에 구조적 차이가 있는지 검정
2. 주문 수량(대량구매 여부)이 취소 발생과 관련이 있는지 확인
3. 특정 상품군에서 취소율이 유독 높게 나타나는지 확인
4. 위 차이들이 통계적으로 유의미한지 검증

## ⚙️ 데이터 전처리

- Invoice 문자열 타입 변환 후, 'C' 시작 여부로 `is_cancelled` 파생
- 결측치 확인: Description 4,382건(0.41%), Customer ID 243,007건(22.77%) — 거래 단위 분석에는 지장 없어 별도 처리하지 않음
- InvoiceDate에서 요일(weekday), 시간대(hour) 파생
- StockCode 중 회계·시스템 처리 코드(`D`, `S`, `M`, `AMAZONFEE`, `BANK CHARGES`, `ADJUST`)는 실제 판매 상품이 아니므로 상품별 분석에서 제외

---

## 🧠 파생 변수 생성

국가·시간·수량·상품이라는 서로 다른 관점에서 취소율을 비교하기 위해 다음 파생 변수를 생성하였다.

```
is_cancelled = Invoice가 'C'로 시작하는지 여부
weekday, hour = InvoiceDate에서 추출한 요일 / 시간대
quantity_abs = Quantity의 절댓값 (취소 거래는 음수로 기록되므로 규모 비교를 위해 절댓값 사용)
quantity_group = quantity_abs를 5개 구간으로 구간화 (1-5개 / 6-20개 / 21-50개 / 51-100개 / 101개 이상)
```

👉 이를 통해 취소 여부를 국가·시간·수량·상품 등 여러 축으로 교차 비교할 수 있는 기반을 마련하였다.

## 🚨 이상치 처리

- 주문 수량(Quantity)에 극단적으로 큰 값(최댓값 80,995개)이 취소·정상 거래 양쪽에 존재하여 평균 비교 시 왜곡이 발생함을 확인
- 이상치를 제거하는 대신, 수량을 구간화하여 평균이 아닌 **구간별 취소율**로 비교함으로써 극단값의 영향을 완화
- 표본이 지나치게 적은 구간(예: 시간대 6시 41건, 21시 1건, 요일 Saturday 402건)은 통계적으로 신뢰하기 어려운 값으로 판단해 별도로 표시하거나 분석에서 제외

## 📊 데이터 시각화

- **국가별 취소율**: 거래 300건 이상 국가 중 상위 15개국을 막대그래프로 비교
- **요일/시간대별 취소율**: 요일 7일, 시간대(7~20시)별 취소율 막대그래프
- **주문 수량 구간별 취소율**: 5개 구간별 취소율 비교
- **상품별 취소율 Top 10**: 회계 코드를 제외한 실제 상품 코드 기준 취소율 상위 목록
- 시각화를 통해 국가(USA·Japan), 시간대(저녁), 주문 규모(양극단), 특정 상품(Cherry Lights 시리즈)에서 취소율이 두드러지게 높다는 패턴을 관찰

## 📐 통계 분석

### 가설 설정

- **H₀ (귀무가설)**: 각 요인(국가, 요일, 주문 수량)과 취소 여부는 서로 관련이 없다(독립이다).
- **H₁ (대립가설)**: 각 요인과 취소 여부는 통계적으로 유의미한 관련이 있다.

### 분석 방법

- 범주형 변수(국가, 요일)와 취소 여부 간 **카이제곱 검정(Chi-squared test)**
- 수치형 변수(주문 수량)와 취소 여부 간 **t검정(Welch's t-test)**

### 검정 결과

| 요인 | 검정 | 통계량 | p-value | 결론 |
|---|---|---|---|---|
| 국가 | 카이제곱 | 3965.17 | < 0.0001 | 유의미한 관련 있음 |
| 요일 | 카이제곱 | 1263.57 | < 0.0001 | 유의미한 관련 있음 |
| 주문 수량 | t검정 | 2.34 | 0.0193 | 통계적으로는 유의미하나, 극단치로 인해 평균 자체가 왜곡되어 있어 구간별 비교가 더 신뢰할 수 있는 근거로 판단 |

## 📌 분석 결과 요약

- **국가**: 거래 300건 이상 국가 중 USA(23.55%), Japan(16.67%)이 다른 국가(대부분 2~7%대)보다 현저히 높은 취소율을 보이며, 카이제곱 검정으로 통계적 유의성이 확인됨
- **요일/시간대**: Thursday(2.32%), Tuesday(2.14%)가 취소율이 가장 높아 주말이 아닌 평일에 취소가 집중되는, 최초 가설과 반대되는 패턴 관찰(도매 거래 특성으로 해석). 저녁 시간대(18~20시)로 갈수록 취소율이 꾸준히 상승해 20시에는 7.1%에 달함
- **주문 수량**: 6-20개 구간에서 취소율이 1.11%로 가장 낮고, 1-5개(2.23%)·101개 이상(3.55%) 양극단에서 높아지는 비선형 패턴 확인
- **상품**: 회계 코드를 제외한 뒤, StockCode 79323으로 시작하는 "Cherry Lights" 시리즈(7개 색상 변형)의 취소율이 27.82%로 전체 평균(1.83%)의 약 15배에 달함을 확인. 색상과 무관하게 전체 시리즈에서 동일하게 높게 나타나 상품 라인 자체의 구조적 문제 가능성을 시사

> 📌 취소율 상위 목록에는 Cherry Lights보다 수치가 높은 상품(예: 23064, 29.41%)도 있었으나, 해당 상품은 거래 건수가 34건에 불과해 표본 크기가 작은 값은 우연에 의해 높게 나타날 수 있다는 판단 하에 우선순위에서 제외하였다. 반면 Cherry Lights 시리즈는 7개 색상 전체·1,470건이라는 충분한 표본에서 일관되게 높은 취소율을 보여, 우연이 아닌 실제 패턴으로 판단할 근거가 더 명확하다. 즉 **수치의 크기보다 표본 규모와 재현성(반복성)을 우선 기준으로 삼아** 조사 대상을 선정하였다.

### 종합 및 제언

네 가지 요인 모두 취소율과 통계적으로 유의미한 관련이 있었지만, 확신도와 실행 가능성을 함께 고려하면 실무적 우선순위는 다음과 같다.

1. **Cherry Lights 시리즈의 반품 사유를 우선 조사**한다.
2. **초대량 주문(101개 이상)**에 대해 확정 전 재확인 절차를 추가한다.
3. **국가별(USA·Japan) 취소 패턴**은 배송·환율 등 추가 데이터 확보 후 심층 분석할 후속 과제로 남긴다.

## ⚠️ 한계점

- 취소 사유, 고객 유형(개인/기업) 정보가 데이터에 없어 모든 해석은 상관관계 수준에 머무르며 인과관계를 확정할 수 없다.
- 단일 도매업체의 2년치 데이터로, 다른 유통 채널이나 시점에 일반화하기 어렵다.
- 국가별 분석에서 배송 거리, 환율 등 잠재적 교란 변수를 통제하지 못했다.
