# 온라인 도매 거래 취소 패턴 분석: 이탈 신호 조기 포착

## 1. 프로젝트 개요

Online Retail II 데이터셋은 인보이스 번호가 'C'로 시작하면 취소 거래라는 것이 잘 알려져 있습니다. 그런데 이 지식은 대부분의 분석에서 **딱 한 줄로만 소비됩니다.**

> "취소 거래는 분석에 방해되니 제거하고, 정상 거래만으로 매출을 분석하겠다."

즉 '취소 여부'라는 정보는 거의 항상 **전처리 단계에서 걸러내야 할 노이즈**로 취급되고, 그 이후 분석(매출 추이, RFM 세그멘테이션, 판매량 예측 등)의 대상에서는 제외됩니다.

**이 프로젝트는 그 전제를 뒤집습니다.** 취소 거래를 제거하지 않고, 오히려 **"취소 거래 자체가 무엇을 말해주는가"를 핵심 연구 대상으로 삼습니다.** 취소가 특정 국가, 특정 시간대, 특정 상품, 특정 주문 규모에 몰려서 발생한다면, 이는 가격 정책 오류, 상품 품질 문제, 혹은 특정 고객군의 이탈 전조를 나타내는 신호일 수 있습니다. 노이즈로 버려지던 데이터를 신호로 다시 읽어내는 것, 그것이 이 프로젝트의 출발점입니다.

| | 일반적인 접근 | 이 프로젝트의 접근 |
|---|---|---|
| 취소 거래의 위치 | 전처리 단계에서 제거 대상 | 분석의 핵심 대상 |
| 관점 | "취소가 있으니 걸러내자" | "취소가 왜, 어디서 발생하는가" |
| 결과물 | 정제된 데이터로 매출/세그멘테이션 분석 | 취소를 설명하는 요인 규명 |

이 프로젝트는 영국 기반 온라인 도매업체의 실제 거래 데이터(Online Retail II)를 활용해, **취소 거래 자체를 분석 대상으로 삼아 어떤 조건에서 취소가 더 많이 발생하는지**를 규명하는 것을 목표로 합니다.

## 2. 데이터 분석이 필요한 이유

- 유통업체는 취소·반품 발생 시 재고 관리, 배송비, 고객 응대 등 추가 비용이 발생합니다. 그러나 취소가 "왜, 어디서" 집중적으로 발생하는지 파악하지 못하면 문제의 근본 원인에 대응할 수 없습니다.
- 취소는 가격 실수, 상품 품질 문제, 대량주문 관련 리스크, 특정 고객군의 구매 후회 등 여러 원인이 섞여 나타날 수 있어, 직관만으로는 어떤 요인이 실제로 취소에 기여하는지 구분하기 어렵습니다.
- 따라서 데이터를 통해 취소 거래와 정상 거래의 특징을 정량적으로 비교하고, 취소에 유의미하게 연관된 요인을 찾아낼 필요가 있습니다.

## 3. 해결하고 싶은 문제

1. 국가별·요일/시간대별로 취소율에 구조적 차이가 있는가?
2. 주문 수량(대량구매 여부)이 취소 발생과 관련이 있는가?
3. 특정 상품군에서 취소율이 유독 높게 나타나는가, 그렇다면 어떤 특징을 공유하는가?

## 4. 데이터셋 소개

- **출처**: UCI Machine Learning Repository — "Online Retail II" (Kaggle 재배포본)
- **내용**: 2009~2011년 영국 기반 온라인 도매업체의 실제 인보이스(거래) 단위 트랜잭션 로그
- **주요 컬럼**:

| 컬럼 | 설명 |
|---|---|
| Invoice | 인보이스 번호 (앞자리 'C'는 취소 거래) |
| StockCode | 상품 코드 |
| Description | 상품명 |
| Quantity | 주문 수량 |
| InvoiceDate | 거래 일시 |
| Price | 단가 |
| Customer ID | 고객 식별자 |
| Country | 고객 국가 |

- **취소 거래 식별**: Invoice 번호가 'C'로 시작하는 거래를 취소 거래로 정의 (`is_cancelled = Invoice.str.startswith('C')`)

## 5. 분석 계획

### Step 1. 데이터 전처리
- Customer ID 결측치 확인 및 처리 방침 결정
- 취소 여부(`is_cancelled`) 파생 변수 생성
- 거래 일시에서 요일·시간대 파생 변수 추출

### Step 2. 탐색적 데이터 분석 (EDA)
- 전체 거래 대비 취소 거래 비중 확인
- 국가별 취소율 비교 시각화
- 요일·시간대별 취소율 비교 시각화
- 주문 수량과 취소 여부의 관계 확인 (대량주문일수록 취소가 많은가)
- 취소율이 높은 상위 상품 목록 도출

### Step 3. 요인별 유의성 검증
- 범주형 변수(국가, 요일 등)와 취소 여부 간 카이제곱 검정
- 수치형 변수(수량, 단가)와 취소 여부 간 차이 검정

### Step 4. (심화, 시간 여력 시) 간단한 예측 모델
- 로지스틱 회귀를 활용해 위 요인들이 취소 여부를 얼마나 설명하는지 확인
- 계수(coefficient)를 통해 어떤 요인이 취소에 가장 크게 기여하는지 해석

### Step 5. 결론 정리
- 취소에 가장 크게 연관된 요인 2~3가지를 정리
- 유통업체 관점에서 이 결과가 시사하는 실무적 함의 정리 (예: 특정 국가/상품군에 대한 정책 재검토 필요성 등)

## 6. 사용 도구

- **Python**: pandas, numpy (데이터 처리) / matplotlib, seaborn (시각화) / scipy (통계 검정) / scikit-learn (로지스틱 회귀)

## 7. 기대 효과

이 분석을 통해 유통업체가 취소·반품 비용을 사전에 줄이기 위해 어떤 지점(국가, 시간대, 상품군, 주문 규모)을 우선적으로 점검해야 하는지에 대한 데이터 기반 근거를 제시하고자 합니다. 이는 단순 매출 분석을 넘어, 거래 리스크를 조기에 포착하고 대응하는 실무형 문제 해결로 이어질 수 있습니다.

무엇보다 이 프로젝트는 "버려지는 데이터에서 의미를 읽어내는 관점"을 보여줍니다. 전처리 단계에서 무심코 지나칠 수 있는 정보도, 관점을 바꾸면 핵심 인사이트의 원천이 될 수 있다는 것이 이 프로젝트가 전달하고자 하는 메시지입니다.

## 9. 분석 결과

전체 1,067,371건의 거래 중 취소 거래는 19,494건으로, 전체 취소율은 1.83%였다.

9-1. 국가별 취소율

거래 300건 이상을 확보한 국가 중 USA(23.55%), Japan(16.67%)이 유럽 국가들(대부분 2~7%대)에 비해 현저히 높은 취소율을 보였다. 두 국가 모두 500건 이상의 충분한 표본(USA 535건, Japan 582건)을 확보하고 있어, 이는 소수 사례에 의한 우연이 아닌 구조적 패턴으로 판단된다. 다만 정확한 원인(배송 거리, 환율, 특정 대량 구매자 등)은 데이터만으로 확정할 수 없어 후속 분석 과제로 남겨둔다.

9-2. 요일별·시간대별 취소율
요일: Thursday(2.32%), Tuesday(2.14%)가 취소율이 가장 높고, Sunday(0.79%)가 가장 낮았다. 이는 "주말이 충동구매성이라 취소가 더 많을 것"이라는 최초 가설과 반대되는 결과로, 이 데이터가 일반 소비자(B2C)가 아닌 도매(B2B) 거래이기 때문에 주중 업무시간에 구매 결정 번복이 더 많이 일어날 가능성을 시사한다. Saturday는 전체 거래가 402건으로 다른 요일(15만~20만 건)에 비해 극히 적어, 해당 요일의 취소율(0%)은 표본 크기 문제로 별도 해석이 필요하다.
시간대: 6시(41건), 21시(1건)는 표본이 지나치게 적어 분석에서 제외했다. 거래가 충분한 7~20시 기준으로는, 오후 중반(13~15시)이 가장 낮은 취소율(1.4~1.6%)을 보이고 저녁으로 갈수록(18~20시) 취소율이 꾸준히 상승해 20시에는 7.1%까지 올라간다.
9-3. 주문 수량과 취소율

주문 수량과 취소율은 단순 비례 관계가 아니라 비선형적인 패턴을 보인다. 6-20개 구간에서 취소율이 1.11%로 가장 낮고, 이보다 작은 구간(1-5개, 2.23%)과 훨씬 큰 구간(101개 이상, 3.55%) 양쪽에서 다시 높아진다. 101개 이상 초대량 주문의 취소율(3.55%)은 최저 구간의 3배 이상에 달하며, 전체 거래 중 비중은 1.1%에 불과하지만 취소율이 유독 높아 관리가 필요한 리스크 구간으로 볼 수 있다. 각 구간 모두 최소 11,706건 이상의 표본을 확보하고 있어 이 패턴은 표본 크기에 의한 왜곡이 아닌 것으로 판단된다.

9-4. 상품별 취소율

상품 코드에는 D(할인), AMAZONFEE(수수료), BANK CHARGES(은행 수수료), ADJUST(수기 조정) 등 실제 판매 상품이 아닌 회계·시스템 처리 코드가 포함되어 있어, 이를 제외한 뒤 재분석했다. 그 결과 StockCode 79323으로 시작하는 "Cherry Lights" 시리즈(7개 색상 변형)가 취소율 상위 목록에 동시에 포함되는 것으로 나타났다. 이 시리즈 전체를 합산하면 1,470건 중 409건이 취소되어 취소율 27.82%로, 전체 평균(1.83%)의 약 15배에 달한다. 7개 색상 모두에서 동일하게 높은 취소율이 나타났다는 점에서, 이는 특정 색상의 문제가 아니라 해당 상품 라인 자체의 구조적 문제(제품 하자, 계절성 상품 특유의 반품 패턴 등)일 가능성을 시사하나, 반품 사유 데이터가 없어 정확한 원인은 확정할 수 없다.

9-5. 종합

취소율에 유의미한 차이를 만드는 세 가지 축은 (1) 국가(USA·Japan이 특히 높음), (2) 주문 규모(초소량·초대량 양극단에서 높음), (3) 특정 상품 라인(Cherry Lights 시리즈)이었다. 다만 이 데이터에는 취소 사유, 고객 유형(개인/기업) 정보가 없어 모든 해석은 상관관계 수준에 머무르며, 인과관계 확정에는 추가 정보가 필요하다.
